# BasketballCraft 2.0.2 – Zuschauer-Quellcode-Patch

- `/bc spectate` schaltet den Vanilla-Spectator-Modus ein/aus.
- Auch Zuschauer sehen während COUNTDOWN/LIVE die Match-Sidebar mit Spielstand, Restzeit und Top-Scorern.
- Pausierte Matches zeigen PAUSE und eine eingefrorene Restzeit.
- Spieler in laufenden Matches dürfen nicht in den Zuschauer-Modus wechseln.
- Bereits vorhandene Team-/Lifetime-Leaderboards bleiben unverändert.
- Bei Zuschauerwechsel wird die Anzeige sofort aktualisiert.

**Wichtig:** Dies ist Quellcode, keine kompilierte oder getestete JAR. Der Streetball-1v1-Modus ist hier noch nicht implementiert. Build mit Java 21 und Maven über GitHub Actions.
