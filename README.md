# BasketballCraft v1.3 – Event Polish (Source)

Changes from v1.2:
- Right-click steal while standing or sneaking, aimed at visible ball; three-second cooldown after a valid in-range attempt.
- Three seconds of anti-counter-steal protection for new ball carrier.
- Actionbar countdown while steal cooldown is active.
- Alternating subtle purple scoreboard dividers and red YouTube label.
- Block break, block place and item drop blocked for active team players during event.
- Outside matches no permanent gamemode changes.

Build via GitHub Actions (`.github/workflows/build.yml`) on Java 21 / Paper API 1.21.11. Not compiled or tested in-game in this environment.
